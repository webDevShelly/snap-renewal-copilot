# SNAP Renewal Copilot

A consent-first renewal assistant that spots upcoming SNAP deadlines, checks what is missing, asks the household for documents, and prepares a renewal draft for review.

## Demo story

Maria's benefits end in 45 days. Trigger.dev starts a renewal workflow; the agent checks her mock SNAP portal, sees that a pay stub is missing, emails a Dropbox upload link, and creates a ready-to-review renewal draft once the document arrives. Submission always requires explicit user confirmation.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Architecture

```text
Trigger.dev sweep → agent route → SNAP tool (mock adapter)
                              ↘ per-user knowledge base
Agent → email/SMS → household → Dropbox upload link
```

## Sponsor hooks

- **Trigger.dev:** `trigger/renewalSweep.ts` is the daily deadline sweep / durable-workflow boundary.
- **OpenAI:** replace the deterministic agent planner in `src/lib/agent.ts` with structured JSON output and validate it before state changes.
- **Exa:** add a `ruleAlerts()` implementation that searches for rule changes since the household's last renewal.
- **Dropbox:** replace the demo URL generated by `createUploadRequest()` with a Dropbox file-request URL.

## Safety boundary

`snapTool` deliberately uses demo data. A production version must not retain portal passwords, must use a state-approved integration or user-operated browser session, and must require user confirmation immediately before submission.
